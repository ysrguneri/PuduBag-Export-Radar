PuduBag Export Radar v0.2

Bu sürüm v0.1 demo arayüzünün üzerine gerçek veri entegrasyonu için güvenli backend katmanı ekler.

İçerik:
- Demo arayüz (API bağlanana kadar çalışır)
- Supabase PostgreSQL gerçek veri şeması
- ImportYeti Edge Function adapter
- Hunter Edge Function adapter
- Buyer ingest + PuduBag skor pipeline
- CRM ve watchlist tabloları
- Kaynak/kanıt/observed_at/verified_at metadata alanları

ÖNEMLİ: API secret'larını frontend'e koymayın.
Kurulum için DEPLOYMENT-REAL-DATA.md dosyasını okuyun.
